RELATÓRIO — FNCP CONTROL
1. Objetivo do projeto
O projeto se chama FNCP Control.

É um sistema web local para acompanhamento de FNCPs, com dados vindos do Jira. O projeto possui Java/Maven no backend e HTML/CSS/JavaScript no frontend.

O servidor local roda em:
http://127.0.0.1:8081

O projeto está localizado em:
C:\Users\bruno.lima\OneDrive - Lockton\Documentos\FNCP_Control_Revisado\FNCP_Control_Revisado

2. Estrutura principal
Na raiz do projeto existem/foram utilizados:
FNCP_Control_Revisado
│
├── src
├── target
├── fncp-importacao.json
├── FNCP_Control_Integrado.html
├── iniciar_FNCP_Control.bat
├── pom.xml
├── README.md
└── RELATORIO_TESTES.md

O frontend usado pelo servidor Spring/Java precisa estar em:
src\main\resources\static\

O arquivo principal precisa se chamar:
index.html

Portanto:
C:\Users\bruno.lima\OneDrive - Lockton\Documentos\FNCP_Control_Revisado\FNCP_Control_Revisado\src\main\resources\static\index.html

3. Backend
A classe principal do servidor é:
br.com.fncp.jirateste.FncpApiServer

O projeto usa Maven.

Para entrar na pasta correta:
cd "C:\Users\bruno.lima\OneDrive - Lockton\Documentos\FNCP_Control_Revisado\FNCP_Control_Revisado"

É obrigatório executar Maven nessa pasta, porque é onde está o pom.xml.

Se estiver em:
C:\WINDOWS\system32

não executar Maven dali.
4. Compilar o projeto
Depois de entrar na pasta do projeto:
mvn -q compile

Se quiser fazer uma limpeza completa:
mvn -q clean compile

Porém, anteriormente o clean apresentou erro porque o Windows/OneDrive estava mantendo arquivos dentro de target em uso.

Quando isso aconteceu, foi possível resolver removendo o target manualmente:
Remove-Item ".\target" -Recurse -Force

e depois:
mvn -q compile

5. Iniciar o servidor
Depois de compilar:
mvn -q "-Dexec.mainClass=br.com.fncp.jirateste.FncpApiServer" exec:java

Cuidado: o comando correto termina em:
exec:java

Não pode ficar:
exec:javamvn

nem:
exec:javab

nem:
exec:javamvn -q

O resultado esperado é semelhante a:
FNCP Control Revisado em http://127.0.0.1:8081
Modo: somente leitura
Arquivo de dados: C:\Users\bruno.lima\OneDrive - Lockton\Documentos\FNCP_Control_Revisado\FNCP_Control_Revisado\fncp-importacao.json

Enquanto esse processo estiver rodando, não fechar essa janela do PowerShell.
6. Abrir o sistema
Com o servidor funcionando, abrir no navegador:
http://127.0.0.1:8081

Se aparecer:
{
  "erro" : "Front-end não encontrado. Execute o servidor na raiz do projeto."
}

verificar se existe:
src\main\resources\static\index.html

Comando para verificar:
Get-Item ".\src\main\resources\static\index.html" | Select-Object FullName,Length

Para listar os arquivos:
Get-ChildItem ".\src\main\resources\static" | Select-Object Name,Length

- CSS
- JavaScript
O arquivo precisa ficar dentro de:

O arquivo que está sendo trabalhado deve ser tratado como arquivo completo, não como uma página que deve ser reconstruída do zero.

Em determinado momento foi criado um index.html incorreto e o sistema abriu, porém:

- vários botões deixaram de funcionar;

Portanto, a regra para a próxima IA é:

NÃO substituir funções existentes sem necessidade.

Fazer somente alterações cirúrgicas no HTML fornecido pelo usuário.

12. Empresa
No filtro:
EMPRESA

devem aparecer todas as empresas existentes nos dados/cadastro do sistema.

Não remover empresas existentes.

A opção inicial deve permitir:
Todas as empresas

13. Status
No filtro:
STATUS

devem aparecer todos os status existentes no sistema.

Não simplesmente inventar ou reduzir a lista.

A opção inicial deve ser:
Todos os status

14. Cards do Dashboard Mensal
Devem existir:
Gasto anual
Deve representar o gasto:
01/01 do ano selecionado

até:
data presente

Ou seja, não é simplesmente um valor fixo do ano inteiro quando estamos no meio do ano.
Gasto do mês
Deve mostrar o gasto correspondente ao mês selecionado.

Se o usuário selecionar:
Outubro

deve mostrar somente Outubro.
15. Remover do Dashboard Mensal
Não utilizar:
FNCPs pagas

porque não existe uma data fixa de pagamento que permita tratar isso como um indicador confiável.

Também não utilizar:
Média

16. Gráfico Gasto Mensal
O gráfico deve apresentar:
Janeiro
Fevereiro
Março
...
Dezembro

com barras.

Cada barra deve mostrar o valor gasto daquele mês.

O valor deve aparecer acima da barra.

Exemplo conceitual:
             R$ 25.000
                 │
              ████
              ████
              ████
              ████
              ████
────────────────────────
 Jan   Fev   Mar   Abr

Quando o usuário clicar em uma barra:
o Dashboard Mensal deve selecionar aquele mês e atualizar os dados correspondentes.

17. Gasto por empresa
O card:
Gasto por empresa

deve mostrar as empresas que tiveram gastos no período selecionado.

Se o mês selecionado for:
Agosto/2026

deve mostrar os gastos das empresas em Agosto/2026.

A ordenação deve permitir visualizar as empresas com maiores gastos primeiro.
18. Lançamentos
O título deve ser:
Lançamentos do mês

e não:
Últimos lançamentos

Quando o usuário escolher um mês, devem aparecer os lançamentos daquele mês.
19. FNCP → Jira
Na tabela de:
Lançamentos do mês

a coluna FNCP deve ser clicável.

O usuário quer o mesmo comportamento que já existe no Dashboard Fiscal.

Ao clicar na FNCP, deve abrir a respectiva issue no Jira.

O formato de URL do Jira é:
https://locktonbrasil.atlassian.net/browse/CHAVE-DA-FNCP

Exemplo conceitual:
FNCP-1234

vira:
https://locktonbrasil.atlassian.net/browse/FNCP-1234

O ideal é reutilizar a função/link que já existe no Dashboard Fiscal, em vez de criar uma lógica diferente.
